Required endpoints
ENDPOINT	EXPECTED BEHAVIOUR	HOW TO VERIFY

POST /predict	Validate one EV charging record, call model.predict(), return predicted energy_kwh in kWh.	Use Swagger /docs with valid sample input.

Prediction input contract
FIELD	TYPE / RULE
battery_start_pct	Number; percentage value.
session_minutes	Number in MINUTES for every station type. Highway input must already be converted to minutes.
charger_kw	Number; charger power in kW.
temp_c	Number; temperature in Celsius.
vehicle_age_yr	Number or null; the trained pipeline imputes missing numeric values.
queue_before	Integer or numeric queue count.
vehicle	One of: car, three_wheeler, two_wheeler.
station_type	One of: Mall, Highway, Residential (match training categories).

MODEL URI WARNING
Do not assume models:/MP236_EV_Energy_Prediction_Model/1 exists on a fresh teammate machine. It exists only in the owner’s local MLflow registry unless a shared tracking server is configured. For Docker, the API must load a model artifact available inside the container or connect to an intentionally configured shared MLflow server.

Implementation checklist
•	Load the model once at application startup; do not reload it for every request.
•	Use Pydantic for input validation and reject unsupported vehicle/station categories with a clear 4xx response.
•	Create a pandas DataFrame with the exact eight feature columns and expected column names before calling predict().
•	Return a JSON response such as {"predicted_energy_kwh": 27.4, "model_version": "1"}.
•	Do not accept or use kwh_billed_in_app: it is a leakage column and is unavailable at prediction time.
•	Handle model-load errors and prediction errors cleanly. Do not expose local file paths, secrets or stack traces in API responses.

Common blockers
PROBLEM	WHAT TO CHECK
Cannot push to origin	Correct GitHub account signed in? Invitation accepted? Username listed with Write access? Correct remote URL?
DVC pull fails	Is a remote configured? Is the remote reachable? Does the teammate have storage credentials / remote access? Do not commit secrets.
Model URI not found	Expected on a fresh clone because mlflow.db and mlruns are local/ignored. Recreate the model locally or use the agreed shared model artifact.
CI cannot find train_cleaned.csv	The file is generated and ignored. Run DVC pull + preprocessing in CI, or change tests to use fixtures.
Docker starts but API cannot load model	The model artifact is not inside the image or the configured shared model store is unavailable. Check the model path and container working directory.
Kubernetes ImagePullBackOff	The cluster cannot see the local image or image tag. Load/build the image for the active cluster and check the Deployment image field.

Do one small task at a time. Test locally, commit from the contributor’s own GitHub identity, push that contributor’s branch to the original shared repository, and use a Pull Request for review. Never put mlflow.db, mlruns/, .venv/, DVC credentials or raw/generated datasets into Git by accident.
