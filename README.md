## About the Project

This project is part of the SCSE3040 MLOps mini project. We are working on an EV Charging Session Energy prediction problem based on data from Guwahati.

The aim is to build a machine learning model that predicts the energy consumed during an EV charging session. Along with model development, we will work on the complete MLOps workflow, including data versioning, experiment tracking, deployment and model monitoring.

## Project Work

The project will cover the following stages:

1. Dataset analysis and identification of data quality issues.
2. Data cleaning and preprocessing.
3. Model training and evaluation.
4. Experiment tracking and model registration using MLflow.
5. Building a prediction API using FastAPI.
6. Containerization using Docker.
7. Automated testing through GitHub Actions.
8. Kubernetes deployment.
9. Data drift monitoring and model retraining.
10. Generating predictions on the holdout dataset.
